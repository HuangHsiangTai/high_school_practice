# 依科目核對

只讀本次題目相關段落。混合科目時按各題適用領域處理；這些核對點補充獨立解題，不限定使用某個公式或固定解法。

## 數學

- 核對定義域、分母不為零、根號與對數條件、端點及嚴格／非嚴格不等式。
- 平方、約分或代換後檢查增根與漏解；以原式代回，確認答案集合完整。
- 幾何圖的示意比例不當成額外條件；變化練習應重新確認條件可同時成立，且有合理解。
- 機率及計數題說明樣本空間與是否等可能，避免把排列與組合混用。

## 物理

- 明定參考系、正方向、初始條件、單位及模型假設；分清向量與量值、速率與速度。
- 用量綱、代回運動方程或極端情況檢查數值與結論。相對運動使用相對初速；釋放物體是否保有載具初速須說明。
- 圖表核對軸的物理量、斜率／面積意義、初始斜率與凹向；高中方法足夠時不要求學生先會微積分。
- 不確定度先確認給定數值的意義及獨立性，再選擇傳遞規則，保留計算值與取位依據。

## 化學

- 反應式核對元素與電荷守恆，保留物態、反應條件、可逆符號及必要的離子電荷。
- 計量先辨認莫耳數、限量試劑、濃度定義與體積單位；氣體計算核對溫度尺度及適用條件。
- 酸鹼、平衡與氧化還原題說明所採模型；使用近似時檢查成立範圍，而非套用不合條件的公式。
- 變化練習的化學式、反應與條件需能支持唯一答案或完整多選集合。

## 生物

- 判斷題先指出適用的生物、細胞、構造、生命階段或實驗條件，避免把有條件結論擴大成所有生物皆成立。
- 遺傳題核對基因型、表現型、顯隱性、連鎖／獨立分配及機率條件；系譜圖保留性別與親緣關係。
- 實驗與圖表題分開描述觀察結果與可支持的推論，辨認控制變因、對照組、樣本與相關／因果差異。
- 機制解析寫出因果關係與證據，不為了湊公式把概念題硬寫成計算題。變化練習需有足夠條件，避免依未交代的物種差異決定答案。

## 需要查證時

對不確定的學科事實，查課本可核對的定義、官方課程資料、學術機構或其他第一手權威來源；外部資料補充背景，不取代原卷的題目條件。實際引用的連結與必要摘要可內嵌於教材，教學內容本身仍能離線讀取。
