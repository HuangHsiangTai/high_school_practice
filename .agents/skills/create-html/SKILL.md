# create_html：高中錯題互動教材

將指定錯題變成高中生能自行操作的教學教材。預設繁體中文；單一 HTML 內嵌內容、樣式、程式與必要圖形，直接以瀏覽器開啟即可離線使用。沿用使用者指定的語言、輸出位置及其他選擇。

## 輸入與範圍

- 輸入為考卷 JPG/JPEG 檔案、目錄或附件，以及錯題清單，例如「單選 1、4、14；多選 23、24」。以「題型＋題號＋必要時的小題」識別題目，避免不同大題重新編號造成混淆。
- 目錄輸入時，逐張查看其中所有 JPG/JPEG，以頁碼與題號確認跨頁題幹、共用條件與圖表；題目範圍以指定清單為準。標記、學生作答與紅筆批改均為輔助資訊，正解須獨立驗證。
- 未指定輸出位置時，寫到考卷目錄，命名為「考卷名稱_互動解題.html」；附件則寫到可交付的工作目錄。只更新本次教材，保留其他既有作品。
- 缺少錯題清單或題目識別有多種合理解讀時，提出具體問題；其餘能由圖片、目錄或既有教材查得的資訊自行確認。清楚的請求直接執行，無需額外訪談或核准設計。

## 辨識、解答與交接

依序完成「辨識定稿 → 獨立解題 → 比對審核 → 製作 HTML」。可用且允許使用 `spawn_agent` 時，由辨識 agent 整理並核對題目，定稿後才交給解題 agent（可分批處理已定稿的題目），審核通過後交給另一位製作 agent。尚未定稿的題目不得開始解題；只暫停受影響題目，其餘已定稿題目可繼續。

首輪解題只提供定稿題幹、選項、必要乾淨圖片及中性的辨識疑義，不提供預期答案、其他人的結論或紅筆批改。主 agent 或另一位審核者先依相同版本題目形成並記錄獨立判斷，再與已提交的解答比對。分歧時提供具體文字、圖中位置與學科證據供重新核對，不先指定答案。委派不可用時自行依序完成上述階段，並如實區分自行複核與另一位 agent 的獨立驗證。

交接或保存題目資料時，讀取 [references/data-contract.md](references/data-contract.md)，依其 `questionVersion` 規則定稿、更新及比對題目與解答；缺少版本或版本不同時，停止合併該題。更正題面後須更新版本並重新驗證相關解答；舊資料先核對再補上版本。中間資料可放暫存目錄；僅在需要保留辨識紀錄或後續更新時留在輸出目錄。HTML 本身須能獨立運作。

1. **辨識完成條件**：每個交付解題的題目都有完整印刷題幹、選項、單位、必要圖表、可回溯的來源頁及已定稿版本。放大或裁切核對會影響答案的符號、次方、根號、正負號，以及「正確／錯誤」「末／未」等文字。依下方圖片處理規則完成必要圖示的清理與比對；仍會影響答案的辨識疑義須先解決，才可定稿。
2. **解答完成條件**：每題及其變化練習均經獨立推導與檢查；多選逐項判斷並確認完整答案集合。依科目讀取 [references/subject-checks.md](references/subject-checks.md) 的相關段落。逐題將計算結果與原卷選項比對，標記「已驗證／題面有疑義／未解決」。只有結果確實相符，或依題目明定的近似規則能得到該選項時，才標為答案。不相符時先重查原圖與推導；仍矛盾則以「原題選項有疑義」為答案區標題，列出結果及差異。最近選項只能註明為可能的命題意圖，不能當作已驗證答案，也不能杜撰取整規則來湊答案。
3. **交付前審核**：主 agent 確認獨立判斷與已提交解答的比對結果，檢查推導、選項分析與最終答案一致，並核對圖形是否表達同一組條件。用代回、另一種推法、量綱、特殊值或反例檢查重要結論，不能只檢查 JSON 可否解析。製作前再核對題目與解答的 `id`、`questionVersion` 及圖片比對結果；分歧未解決的題目不得標為已驗證。

無法辨識且會改變答案的內容，不猜寫成確定題幹；只暫停受影響題目並索取清晰圖片或文字，其餘先處理。

## 每題的教學內容

依序呈現：

1. **原題**：完整條件、選項與必要圖表，保留原題的問法及應選項數。
2. **讀題切入點**：簡要指出關鍵條件、所求、可用觀念，以及為何選擇這個方法。這是可教學的解題策略，不是冗長的內心獨白。
3. **逐步推導**：由條件到結論，每步交代採用的關係、代入與意義。優先使用高中課程內的方法；額外方法可作選讀補充。預設先顯示第一步，讓學生逐步揭示，也可一次展開。
4. **答案與選項分析**：推導全部展開後揭示，解釋選項的成立或錯誤原因。問「何者錯誤」時清楚標示所選項目是錯誤敘述。有疑義時以疑義說明取代武斷的標準答案。
5. **注意事項**：針對該題指出易混淆概念、適用條件及常見失誤。
6. **一題變化練習**：保留核心觀念，改變條件、問法、表示方式或情境，讓學生遷移方法；不只換符號重抄原題。另行驗算題幹、選項、答案及完整解析。學生先作答，送出後再揭示回饋與解析。

### 原題圖片處理

- 預設使用去除手寫筆跡後的原題裁圖，完整保留解題所需的構造、標籤、圖例、座標軸及數值；排除姓名、座號與無關頁面內容。無手寫筆跡的圖可直接裁切使用。
- 將清理前後圖片逐一比對，確認印刷內容完整保留。手寫筆跡遮住且無法確認的資訊列入辨識疑義，暫停受影響題目並索取清晰圖片或文字，不自行補畫成確定條件。
- 複雜圖形使用清理後的點陣圖片；僅簡單幾何圖、座標圖或流程示意可採 SVG，並標示「重繪示意」。完成後與原圖並列核對形狀、位置關係、座標、起終點、凹向、方向、比例註記及標籤；影響解題的差異須修正並重新比對後才能交付。
- 在交接資料的 `diagram` 中記錄原圖來源、處理後圖片位置、呈現方式及比對結果，欄位依交接契約。必要圖片完整內嵌至 HTML，保留可離線使用的要求。

## HTML 互動

- 題目導覽、上／下一題、上／下一步、展開全部推導與重設本題。
- 練習依其自身題型使用單選、多選、數值或文字輸入；不以原題題型推定練習題型。多選比對完整集合，數值題明定單位及合理容許誤差，文字題事先定義可接受答案。
- 未作答時給提示並保留隱藏解析；送出後顯示判分與解析。重作清空作答、隱藏解析，讓學生再次嘗試。
- 各題分別保留本次頁面開啟期間的推導進度、作答及判分，切換題目後可接續。若顯示完成統計，只有練習答對才算完成，重設或重作會清除該題完成狀態。重新開啟仍要保存時，才依需求加入本機儲存。
- 行動版排版、原生可聚焦控制項、輸入標籤、鍵盤操作與可讀取的動態回饋。列印時展開目前列印範圍的推導與解答，並隱藏操作按鈕。
- 公式用離線可讀的 HTML、MathML、SVG 或內嵌資源，不能把未渲染的 LaTeX 原碼當成公式顯示。必要圖片及程式也須內嵌，避免 CDN、遠端字型或依賴同目錄 JSON 才能開啟。

## 驗證與交付

確認所有指定題目各出現一次，每題都有完整教學與一題變化練習。實際操作導覽、上／下一步與揭示時機、未作答提示、答錯、答對、部分多選集合、重作、跨題進度、最後一題完成及重設。優先用可用的瀏覽器測試；DOM 測試可驗證狀態與事件，但不能取代圖形與排版檢視。

檢查可離線開啟、無執行錯誤，並以桌面與窄螢幕檢視圖文；測試資源不足時完成可做的檢查，交付時如實說明未驗證範圍。最後提供 HTML 檔案連結、涵蓋題目與重要原題疑義，簡短說明已做的驗證。只有使用者要求時才發布網站或更改目錄首頁。
