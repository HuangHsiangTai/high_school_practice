高中練習教材

選擇下方 HTML 頁面開始練習。新增的 HTML 檔案會自動列在這裡。

    {%- assign page_files = site.pages | sort: "path" -%} {%- for item in page_files -%} {%- assign extension = item.path | split: "." | last | downcase -%} {%- unless item.path == "index.html" or extension != "html" -%}
  • {{ item.name | default: item.path | split: "/" | last | escape }}{{ item.path | escape }}
    • {%- endunless -%} {%- endfor -%} {%- assign static_files = site.static_files | sort: "path" -%} {%- for item in static_files -%} {%- assign extension = item.extname | downcase -%} {%- unless item.path == "/index.html" or extension != ".html" -%}
  • {{ item.name | escape }}{{ item.path | remove_first: "/" | escape }}
    • {%- endunless -%} {%- endfor -%}
